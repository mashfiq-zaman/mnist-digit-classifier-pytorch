# MNIST Digit Classifier — PyTorch

A feedforward neural network trained on the MNIST dataset to classify 
handwritten digits (0–9) with ~97% test accuracy.

## What I learned
- PyTorch tensors, autograd, and training loops
- Building models with nn.Module and nn.Sequential
- DataLoaders and batch training
- Model evaluation and saving with torch.save()

## Tech Stack
- Python
- PyTorch
- torchvision
- matplotlib

## How to Run
pip install torch torchvision matplotlib
python mnist_classifier.py

## Results
- Training epochs: 5
- Test Accuracy: ~97%
